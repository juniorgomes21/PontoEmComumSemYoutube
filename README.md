# Ponto em Comum

Web application developed with React and TypeScript using Vite.

The project provides a web-based interface built around the Ponto em Comum concept, with client-side navigation, API integration and reusable React components.

## Features

- React-based web application
- TypeScript
- Client-side routing
- API integration
- Responsive user interface
- Reusable components
- Interactive content
- Modern frontend development workflow

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router
- Material UI
- Emotion
- Styled Components
- React YouTube

## Architecture

The application follows a component-based React architecture.

The main parts of the project include:

- React components
- Application pages
- Client-side routing
- API communication
- UI components
- Styling and layout

The application uses Axios for HTTP communication and React Router for client-side navigation.
